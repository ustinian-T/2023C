
论文正文可直接依据 `../modeling/README.md` 的模型定义和 `../outputs/` 的实算结果撰写。推荐叙述顺序为：候选口径与数据约束、动态 SKU 份额、Q2 品类需求向 SKU 的映射、价格离散化、词典序 MILP、K 前沿、基线对比与局限。

需要明确披露两点：一是主模型优化“尽量满足品类需求”而非保证全部潜在需求；二是最差 10% 平均利润仍为负值，说明在成本与需求共同不利的日期存在经营风险，不能只报告期望利润。Q1 结果因覆盖不足仅作诊断，不应写成已证实的替代效应。

稳健性部分应报告：代表/完整场景服务损失差 0.00749、六折满足率标准差 0.00940、9 组变体最低选品 Jaccard 0.833。历史份额权重从 0.25 调至 0.75 时，满足率由 82.83% 降至 71.86%，期望利润由 356.56 元降至 -51.83 元，因此不能把 SKU 份额当作无关紧要的固定比例。采购上限提高会单调改善服务，但减少采购反而提高期望利润，体现“品类需求优先”与利润之间的真实冲突。
