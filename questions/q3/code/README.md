# 代码目录

- `q3_model.py`：候选识别、动态份额、价格网格、第二问场景复用、两阶段词典序 MILP、K=27-33 前沿、9 组灵敏度重求解和完整场景评估；
- `test_q3_model.py`：20 项小样本单元测试，覆盖日期边界、收缩份额、价格回退、损耗/成本口径、MILP 约束、Stage 1 等价复用及缓存失效拒绝；
- `validate_q3_outputs.py`：独立输出校验器，执行 83 项候选、价格、订货、会计恒等式、场景泛化、分折稳定性和灵敏度检查；
- `plot_q3_matlab.m`：读取正式 CSV，输出 6 组彩色 PNG/PDF 图表，其中第 6 组为品类结果补充图。

从仓库根目录运行 `python questions\q3\code\q3_model.py`。正式代码固定采用 60 个确定性分位代表场景进行优化、600 个场景进行外推评价，不包含辅助全量重优化开关。默认仅在当前输入、价格网格及 600 场景重算指标均与已有结果一致时复用 K 前沿；`--force-base` 可关闭复用。MATLAB 图表运行 `matlab -batch "run('questions/q3/code/plot_q3_matlab.m')"`。代码只读取共享处理数据及 Q1/Q2 输出，不改动原始附件。
