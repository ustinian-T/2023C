# Q1 模型实现与复现说明（重构版）

## 1. 已完成内容

本目录已按重构方案完成问题 1：

> 两部分布分析 → 月份与季节画像 → K-means 季节型聚类 (k=5) → 四层级四种关系指标分析 → 块 Bootstrap 可信度标记。

除作图脚本 `code/plot_q1_matlab.m` 外，所有数据读取、筛选、分布拟合、聚类、关系计算和验证均由 Python 完成。输入直接采用仓库共享的 `data/processed/` 数据。

旧版 MSTL + MIC + Graphical Lasso 方案保留在 `code/q1_model_legacy_appendix.py` 作为附录对照。

## 2. 逻辑链条

1. **活动度筛选**：251 个单品中，要求销售跨度 ≥ 730 天、正销售日 ≥ 90 天、累计销量 ≥ 100 kg（不设覆盖率门槛，以保留季节性商品），共纳入 64 个单品。
2. **两部分布**：销量含大量零值，先估计零销量概率，再对正销量比较 Normal、Lognormal、Gamma 和 Weibull；AIC 选相对最优，KS 不通过则标记 KDE 回退。
3. **月份与季节画像**：计算各品类和单品 12 个月销量占比、活跃率、季节指数；按气象学四季（春 3-5、夏 6-8、秋 9-11、冬 12-2）汇总四季特征。
4. **季节型聚类**：每单品 24 维特征（12 月销量占比 + 12 月活跃率），标准化后 K-means 聚类。比较 k=2–8 的轮廓系数、CH、DB、最小簇规模和 100 次重采样 ARI，综合选择 k=5。五簇命名为春季型、初夏型、夏秋型、冬季型、常年型。
5. **四层级关系分析**：
   - A. 题设六品类（15 对，完整矩阵）
   - B. 各题设品类内部代表性单品
   - C. 五季节簇之间（聚合销量）
   - D. 各簇内部单品对
6. **四种关系指标**：
   - 12 月季节指数 Pearson 相关（旺季是否一致）
   - 分季节销量 Spearman 相关（去除年月均值）
   - 分季节销量份额 Spearman 相关（区分共同客流与此消彼长）
   - 活跃日 Jaccard 重合度
7. **可信度标记**：7 日移动块 Bootstrap 95% 置信区间 + BH 校正 q 值；|ρ|≥0.30 且区间不跨 0 为较明确关系。

## 3. 核心结果

- 单品层：64 个单品入选，5 个季节聚类，簇规模 [7, 8, 11, 17, 21]。
- 聚类指标：轮廓系数 0.233，CH 15.79，DB 1.48，完整销售年度块重采样 ARI 0.566。
- 品类层：6 品类完整 15 对关系矩阵，不删除弱关系。
- 单品层：完整输出 2016 对机器可读关系，全年有 18 对达到 |ρ|≥0.30 且区间不跨 0。
- 分布：70 个对象中 45 个参数分布通过 KS 检验，25 个 KDE 回退。
- 旧方法对比：旧 MIC + Graphical Lasso 仅得到 10 条严格条件关联边，新方法保留全部关系并用可信度标记区分强弱。

完整数字见 `outputs/results/q1_summary.json`。

## 4. 运行方法

Python 依赖列于 `requirements.txt`。从仓库根目录运行：

```powershell
python questions\q1\code\q1_model.py
```

随后用 MATLAB 绘图（需先安装 MATLAB）：

```powershell
matlab -batch "run('questions/q1/code/plot_q1_matlab.m')"
```

验证输出完整性：

```powershell
python questions\q1\code\validate_q1_outputs.py
```

## 6. 图形规范

所有主图为白底，坐标与图例字号不低于 12–16 pt，使用青绿—蓝紫 SCI 色板。彩色电子版同时以实线/虚线/点线、空心圆/上三角/下三角作冗余编码，使黑白打印不依赖色相仍可辨认。主图 PNG 为 600 dpi，PDF 保留矢量文本。

## 7. 模型优点

1. 放宽单品筛选门槛，保留季节性商品，分析样本从 47 扩大至 64 个。
2. 四种互补关系指标覆盖旺淡季同步性、同期波动、份额竞争和活跃重合，比单一条件相关更全面。
3. 四层级（品类、品类内、簇间、簇内）分析让论文可逐层深入。
4. 块 Bootstrap + BH 校正提供可信度标记，但不以硬阈值删除弱关系。
5. 完整关系矩阵全部保留，正文只突出 |ρ|≥0.30 且 CI 不跨 0 的关系。

## 8. 模型缺点与适用边界

1. 无销售记录可能来自缺货或未上架，不能完全等同于零需求。
2. 份额负相关仅解释为销售结构竞争，不声称价格替代或因果替代。
3. 聚类稳定性在 k≥5 后下降，部分商品（如牛肝菌）的季节模式极特殊。
4. 所有关系均解释为统计共变、季节同步或活跃期重合，不作因果推断。
