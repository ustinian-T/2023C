## 3. 定义与边界验证

1. 月画像先补齐完整实体—日期日历；缺失月份不再从跨年均值中消失。
2. 每个单品12个月销量占比和为1，月活跃率均位于0和1之间。
3. 单品首日以前和末日以后保留为不可观察值；任意一对单品只在共同观察窗口计算关系。
4. 五簇名称唯一，且不存在空簇或单例簇。
5. 聚类稳定性以完整7月—次年6月销售年度为块重采样，100次均有效。
6. 全部64个单品关系母表含 $64\times63/2=2016$ 对，无跨品类、跨簇遗漏。
7. 品类和簇间所有季节关系均执行200次7日移动块Bootstrap；单品层所有 $|\rho|\ge0.30$ 候选关系均具有真实置信区间，未计算区间的弱关系字段保持为空。

## 4. 结果解释检查

六品类全年销量相关整体为正，说明去除年月均值后仍存在共同的短期销售节奏；然而部分份额相关为负，例如花叶类—食用菌约为-0.54。这两类结果不矛盾：总客流上升可使两类商品同时多卖，但它们在当日蔬菜销量结构中的占比仍可能此消彼长。

常年型—夏秋型全年销量相关约为0.32，份额相关约为-0.72，体现“总量同向、结构竞争”。由于每日各类份额之和为1，负份额相关只作为结构竞争线索，不能解释为价格替代。

单品层全年有18对关系达到 $|\rho|\ge0.30$ 且95%区间不跨0。绝对相关较强的代表包括西兰花—净藕(1)（0.44）、西兰花—芜湖青椒(1)（0.44）、七彩椒(1)—红灯笼椒(1)（0.43）和西峡花菇(1)—西峡香菇(1)（-0.33）。所有结果均界定为统计共变，不作因果推断。

## 5. 仍需保留的局限

1. 无销售记录仍可能混合无需求、缺货和未陈列。
2. 只有三个完整销售年度，年度块重采样ARI约0.57，说明聚类为中等稳定而非绝对分类。
3. 销量份额属于组成数据，天然存在负相关约束。
4. 价格、促销、天气和陈列等未观测因素仍可能造成混杂。
5. 旧 MIC + Graphical Lasso 结果只作为附录中的严格条件关联对照。
