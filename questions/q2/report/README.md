# 第二问结果摘要

## 最终主策略

主方案取风险权重 `0.25`、周利润下尾概率 `10%`、缺货商誉成本系数 `0.10`、参考加价率正则权重 `80.0`，输出 2023 年 7 月 1—7 日六类蔬菜共 42 条补货与定价决策。周补货量为 `2048.33 kg`，期望销售量为 `1686.78 kg`。

为避免把模型正则项误写成会计利润，最终结果分四层报告：

| 口径 | 主策略 | 同口径基线 | 含义 |
|---|---:|---:|---|
| 周经营利润期望 | ¥4850.30 | ¥2671.08 | 销售收入减场景采购成本 |
| 周经营利润最差 10% 均值 | ¥1486.03 | -¥700.10 | 对 600 条七日场景先汇总再取下尾 |
| 周服务调整利润期望 | ¥4515.65 | ¥2452.93 | 经营利润再扣预期缺货商誉成本 |
| 周正则化利润期望 | ¥4169.48 | ¥2452.93 | 服务调整利润再扣参考加价正则 ¥346.17 |
| 周正则化利润最差 10% 均值 | ¥302.51 | -¥1100.45 | 实际进入风险目标的尾部口径 |
| 风险调整目标值 | ¥3202.74 | — | 75% 正则化期望 + 25% 正则化下尾 |

因此，相对历史中位加价率与中位需求补货基线，主策略经营利润期望提高 `81.59%`。服务调整利润期望提高 `84.09%`，但该指标包含人为设定的商誉成本，仅用于同参数下比较服务风险，不作为会计收益。摘要和结论优先报告经营利润口径。

## 价格响应的解释边界

水生根茎类和花菜类的条件价格响应置信区间完全低于零；其余品类存在不同程度的弱识别。茄类和辣椒类的原始响应分别为正，不能据此声称“涨价促进需求”，也不能声称已经完成 IV 因果识别。本模型使用全品类交叉拟合残差的合并响应 `-0.2458` 作为这两个品类的经验回退值，并把其加价上界收紧至历史 90% 分位。

该处理的作用是避免把不可靠的近零/正响应直接交给优化器；它仍属于稳健约束而非因果弹性结论。全文将其称为“条件价格响应系数”，只解释控制已有时序特征后的价格—销量关联。若获得促销、天气、客流、竞争价格或可信工具变量，应重新估计价格响应。

## 风险与敏感性分析

风险权重从 `0` 增加到 `0.50` 时，正则化利润期望由 `4184.90 元` 降至 `4098.13 元`，最差 10% 正则化利润由 `205.01 元` 提升至 `413.87 元`；经营利润最差 10% 均值同时由 `1332.54 元` 提升至 `1676.79 元`。这说明主风险权重 `0.25` 位于期望收益与尾部稳健性的中间位置。

商誉成本系数从 `0` 增至 `0.20` 时，周补货量由 `1937.58 kg` 增至 `2109.12 kg`，平均场景缺货概率由 `66.31%` 降至 `57.93%`。这里的概率是 600 条联合模拟场景中需求超过可售量的比例，不等同于现实中相同比例的顾客无法购买。主策略期望需求满足率为 `67.01%`。系数越大，模型越重视服务水平；由于评价口径本身也包含更高商誉成本，不宜直接用不同系数下的正则化评价值判断经营利润优劣。

参考正则权重从 `0` 增至 `500` 时，平均加价率由 `0.9049` 降至 `0.7207`，触及各自品类加价上界的决策由 `35` 条降至 `0` 条，但经营利润期望由 `4871.78 元` 降至 `3962.15 元`。权重 `80` 是敏感性网格中的折中点：有 `14/42` 条价格离开上界，同时未采用会导致明显利润损失的极强正则。

## 预测与场景检验

需求滚动验证加权 WAPE 为 `35.88%`，低于七日季节朴素基线的 `39.85%`；成本加权 WAPE 为 `15.28%`，低于基线的 `15.81%`。名义 80% 需求残差区间平均覆盖率为 `74.36%`，存在轻度欠覆盖，因此最终决策没有把点预测当成确定值，而是用 600 条需求—成本联合七日场景传播不确定性。

历史与场景的 12 维需求—成本相关矩阵最大绝对偏差为 `0.0688`。三档风险方案的周级 SLSQP 均正常收敛；主方案两个可行初值的目标相对差为 `1.68e-8`，补货量没有触及人为上界，加价与跨日平滑约束的最大数值误差低于 `2.31e-8`。

## 结果合理性说明

主要品类的日补货量与最近一周销量量级一致，且所有补货上界均未激活。水生根茎类建议价 `19.11—21.25 元/kg` 高于近一年零售价 95% 分位，主要原因是预测周前最近七日批发均价已升至 `12.56 元/kg`，且模型使用历史加价率而非历史绝对售价定界；该品类同时具有最强负价格响应，建议补货量仅 `7.14—12.85 kg/日`。因此该价格并非计算异常，但属于对成本上涨较敏感的上沿建议，实际执行时应结合当日采购报价滚动更新。

最终 `36/36` 项输出一致性检查和 `13/13` 项手算单元测试全部通过。三档周级 SLSQP 均成功收敛且最终约束满足；逐日差分进化只作为候选初值生成器，未据此宣称全局最优。商誉系数和参考正则仍是管理参数而非外部数据校准量，论文应把敏感性区间与主结果同时呈现。
