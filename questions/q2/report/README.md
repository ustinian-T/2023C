# 第二问结果摘要

主方案取风险权重 `0.25`、尾部概率 `10%`，得到 2023 年 7 月 1—7 日六类蔬菜共 42 条补货与定价决策。周补货量为 `1957.97 kg`，期望销售量为 `1642.65 kg`，期望利润为 `4894.57 元`；在 600 条七日联合场景中，周利润最差 `10%` 场景均值仍为 `1712.35 元`。相较历史中位加价率与中位需求补货基线，期望利润提高 `84.37%`，周下尾利润由 `-721.90 元` 改善至 `1712.35 元`。

风险敏感性结果符合经济预期：风险权重由 `0` 增加到 `0.50` 时，期望利润由 `4938.71 元` 降至 `4750.84 元`，而最差 `10%` 周利润均值由 `1419.87 元` 提升至 `1956.48 元`。主方案位于二者之间，体现收益与抗风险能力的折中。

预测端采用严格时序滚动验证。需求加权 WAPE 为 `35.95%`，低于七日季节朴素基线的 `39.87%`；成本加权 WAPE 为 `15.28%`，低于基线的 `15.81%`。需求残差名义 80% 区间的平均覆盖率为 `74.29%`，因此最终决策没有把点预测当作确定值，而是通过联合残差场景显式传播不确定性。

模型检查共 22 项全部通过：42 条决策完整、价格与成本加成恒等式成立、补货与加价区间无越界、跨日加价变动无实质违规、SLSQP 全部收敛、双初值目标稳定、12 维需求—成本相关矩阵最大偏差为 `0.0693`，且三档风险权重呈现正确的收益—尾部风险方向。

需要如实说明的是，茄类与辣椒类的条件价格弹性原始估计非负且置信区间跨零，代码对其执行了单调负弹性投影，并收紧加价上界。因此这两类的价格建议应视为风险约束下的稳健决策，而不是强因果弹性结论；若获得促销、天气、客流和竞争价格数据，应重新估计价格响应。
