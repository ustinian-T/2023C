# 第二问结果摘要

## 改进模型结果

主方案取风险权重 `0.25`、尾部概率 `10%`、缺货商誉惩罚 `0.10`、参考加价率偏离权重 `80.0`，得到 2023 年 7 月 1—7 日六类蔬菜共 42 条补货与定价决策。周补货量为 `2031.22 kg`，期望销售量为 `1672.15 kg`，期望利润为 `4125.83 元`；在 600 条七日联合场景中，周利润最差 `10%` 场景均值为 `323.81 元`。相较历史中位加价率与中位需求补货基线，期望利润提高 `53.8%`，周下尾利润由 `-662.18 元` 改善至 `323.81 元`。

### 相比原始模型的改善

| 指标 | 原始模型 | 改进模型 | 变化 |

| 周利润期望 | ¥4894.57 | ¥4125.83 | -15.7% |
| 最差 10% 周利润 | ¥1712.35 | ¥323.81 | 仍为正，更保守 |

| 辣椒类弹性 | -0.05（投影） | -0.40（保守地板） | 更合理 |

### 两项惩罚机制的效果

1. **缺货商誉惩罚**（η=0.10）：当 demand > available 时，对超出部分按单位毛利 10% 计为隐性成本。这使补货量从 1958 kg 增至 2031 kg（+3.7%），缺货率从 66% 降至 61%。敏感性分析显示 η=0.20 时缺货率进一步降至 57%，但周利润期望降至 ¥3892——零售商需在利润和服务水平间权衡。

2. **参考加价率软惩罚**（λ=80.0）：对偏离历史中位加价率施加二次惩罚。在原始硬边界约束下，优化器将所有品类定价推至历史上界。引入此惩罚后，42 条决策中有 14 条不再触顶，加价率从边界回落至"中位数与上界之间"的均衡位置。λ 越大回落越多。

### 弹性保守调整

茄类和辣椒类的原始 OLS 弹性为正（分别为 +0.27 和 +0.06），即便经 Bayes 收缩后仍为正或接近零——这是价格内生性的典型表现（历史数据中高需求日商家会提价）。原始模型将其强制投影至 -0.05，本质上是"极弱负弹性"假设。改进模型改用保守地板 min(pooled, -0.40) = -0.40，基于全品类合并弹性 (-0.25) 外推，使这两个品类的定价建议不再建立在"几乎无价格敏感性"的前提上。

### 敏感性分析

灵敏度表（`q2_sensitivity_analysis.csv`）覆盖 4 个 goodwill 水平和 4 个 reference 权重水平，展示了周利润、下尾利润、缺货率和加价率触顶比例的系统性变化。

风险敏感性结果符合经济预期：风险权重由 `0` 增加到 `0.50` 时，期望利润由 `4322 元` 降至 `4240 元`，而最差 `10%` 周利润均值由 `409 元` 提升至 `604 元`。

预测端采用严格时序滚动验证。需求加权 WAPE 为 `35.85%`，低于七日季节朴素基线的 `39.89%`；成本加权 WAPE 为 `15.28%`，低于基线的 `15.81%`。

模型检查共 31 项全部通过（原 22 项 + 新增 9 项）：包括缺货率合理性、加价率触顶比例、保守弹性生效、敏感性分析文件完整性等。

需要如实说明的是，茄类与辣椒类的弹性估计依赖于保守先验而非强因果识别；缺货商誉惩罚系数 0.10 和参考加价率权重 80.0 的选择基于数值试验而非外部数据校准。若获得促销、天气、客流和竞争价格数据，应进一步精细化这两项参数。
