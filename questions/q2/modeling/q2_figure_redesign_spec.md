# Q2 增强版制图方案

本轮只重选图型与增强视觉表达，不修改模型、参数或结果。所有图均由
`outputs/tables` 中的正式 CSV 直接生成，不进行平滑、插值或拟合。

1. **补货与定价轨迹图**：保留 `fig_q2_daily_replenishment_pricing`，用于观察六个品类在七天内的策略变化；颜色、线型和 Marker 共同编码，支持黑白打印。
2. **策略双热力图**：用两个同构矩阵同时呈现 42 条补货量和 42 条售价，避免仅凭折线精确读值的困难；单元格直接标值，作为轨迹图的查表补充。
3. **条件价格响应森林图**：以区间、原始点估计、优化采用值和回退标记同时表达估计大小与识别边界。
4. **收益哑铃图**：只连接同一口径的历史基线与主策略，突出提升方向和幅度，避免分组柱形图对正负值的视觉拥挤。
5. **风险—收益权衡图**：横轴为最差 10% 正则化评价均值，纵轴为正则化评价期望，三点对应三档真实重优化结果，用于解释主风险权重 0.25 的折中位置。
6. **四联敏感性图**：把两个管理参数的四个结果变量拆开，消除双纵轴的尺度歧义；折线只连接真实网格点，不声明连续函数关系。

配色采用低饱和 Nature 风格，并同时使用形状、线型、直接标值和灰度差异，确保信息不只依赖颜色。
