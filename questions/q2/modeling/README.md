# 第二问建模说明

## 1. 条件价格响应

对品类 (c) 的日销量和平均售价定义

\[
Y_{ct}=\ln(Q_{ct}+1),\qquad X_{ct}=\ln P_{ct}.
\]

令 (Z_{ct}) 包含星期、月份、年内周期、趋势、批发成本、历史销量/价格/成本滞后量、移动均值与可售单品数。分别用时序交叉拟合 GBDT 估计

\[
\widehat m_Y(Z)=\mathbb E(Y\mid Z),\qquad
\widehat m_X(Z)=\mathbb E(X\mid Z),
\]

并计算样本外残差 ~Y 与 ~X。条件价格响应系数为

\[
\widehat\theta_c=
\frac{\sum_t \widetilde X_{ct}\widetilde Y_{ct}}
{\sum_t \widetilde X_{ct}^{2}}.
\]

七日移动块 Bootstrap 给出标准误和置信区间。为降低弱识别带来的极端决策，原始估计向全品类合并响应作经验贝叶斯收缩，并投影到 [-3,-0.05]。茄类、辣椒类的原始估计非负且置信区间跨零，可能来自需求旺盛时同步提价等内生性；本数据没有合格的外生工具变量，故不宣称因果弹性或 IV 估计，而使用样本内全品类合并响应 \(\theta_{\mathrm{pooled}}=-0.2458\) 作为回退值。这里的 \(\theta_c\) 只描述控制已有时序特征后的价格—销量关联，是优化中的需求响应参数。置信区间未完全低于零的品类同时使用更保守的历史加价上分位数。

## 2. 基础需求与成本预测

定义剥离价格效应后的基础需求状态

\[
\alpha_{ct}=\ln(Q_{ct}+1)-\theta_c\ln P_{ct}.
\]

GBDT 只使用至少滞后 7 日的销量、价格、成本与滚动统计量，因此预测 7 月 1—7 日时不需要递归填入未知未来销量。模型预测与七日季节朴素预测按滚动验证 WAPE 从 0 到 1 网格选择融合权重。批发成本在对数尺度使用同样的融合机制，保证预测值为正。

给定价格 (p_{ct})，场景 \(\omega\) 下的需求为

\[
D_{ct}^{(\omega)}(p)=
\max\left\{0,\exp\left(\widehat\alpha_{ct}
+\theta_c\ln p+e_{ct}^{(\omega)}\right)-1\right\}.
\]

## 3. 联合场景与利润

每天将六个需求残差和六个成本残差合成 12 维向量，并从连续历史区间抽取长度为 7 的移动块。这样同一场景同时保留跨品类、需求—成本和跨日依赖。批发成本场景为

\[
W_{ct}^{(\omega)}=\widehat W_{ct}\exp(u_{ct}^{(\omega)}).
\]

设损耗率为 \(\lambda_c\)，补货量为 \(q_{ct}\)，则可售量、实际销量及场景经营利润分别为

\[
A_{ct}=(1-\lambda_c)q_{ct},\qquad
S_{ct}^{(\omega)}=\min\{D_{ct}^{(\omega)},A_{ct}\},
\]

\[
\Pi_{\mathrm{op}}^{(\omega)}=
\sum_{t=1}^{7}\sum_{c=1}^{6}
\left(p_{ct}S_{ct}^{(\omega)}-W_{ct}^{(\omega)}q_{ct}\right).
\]

缺货商誉成本与服务调整利润定义为

\[
G^{(\omega)}=\eta\sum_{t,c}\max(0,p_{ct}-W_{ct}^{(\omega)})
\max(0,D_{ct}^{(\omega)}-A_{ct}),\qquad
\Pi_{\mathrm{svc}}^{(\omega)}=\Pi_{\mathrm{op}}^{(\omega)}-G^{(\omega)}.
\]

其中 \(\eta=0.10\)。商誉成本是长期顾客流失的代理量，\(\eta\) 是管理偏好参数而非附件直接给出的客观常数。商誉成本不与会计经营利润混为一项；输出表分别报告二者。

## 4. 风险目标与约束

用服务调整周利润最差 \(10\%\) 场景的均值表示下尾收益 \(L_{0.10}(\Pi_{\mathrm{svc}})\)，目标为

\[
\max\;(1-\gamma)\mathbb E\left[\Pi_{\mathrm{svc}}\right]
+\gamma L_{0.10}(\Pi_{\mathrm{svc}})
-\lambda\sum_{t=1}^{7}\sum_{c=1}^{6}(m_{ct}-m_c^{\mathrm{med}})^2,
\qquad \gamma\in\{0,0.25,0.50\}.
\]

其中 \(\lambda=80.0\) 为参考加价率正则权重，代理未建模的竞争和外推风险，同样属于管理偏好参数。该确定性项只在每周目标中扣除一次。为保持解释严格，程序另外输出经营利润、服务调整利润、正则化评价值和风险目标四种口径；其中只有经营利润对应销售收入减采购成本的会计口径，正则化评价值不解释为实际收益。

这与对损失 \(-\Pi\) 施加 CVaR 惩罚等价，但直接使用下尾利润便于解释。注意必须先在每条场景中汇总七日利润，再计算尾部均值。

价格采用成本加成表示 (p_{ct}=\widehat W_{ct}(1+m_{ct}))。各品类 (m_{ct}) 被限制在近一年历史加价率的 5%—95% 分位区间；弱识别品类上界收紧至 90% 分位。首日及相邻日期满足

\[
|m_{c1}-m_c^{\mathrm{med}}|\le\Delta_c,\qquad
|m_{ct}-m_{c,t-1}|\le\Delta_c,
\]

其中 \(\Delta_c\) 为历史日加价率绝对变化的 90% 分位数。补货量非负，上界取历史损耗修正补货量 99% 分位外扩值与低价场景需求 99% 分位外扩值中的较大者。

## 5. 数值求解

逐日差分进化与局部 SLSQP 用于启发式构造高质量可行候选初值；差分进化达到迭代上限时仍保留其最好可行候选，不据此宣称日问题已达到全局最优。最终模型把 42 个加价率和 42 个补货量同时交给周级 SLSQP。需求受限时利润对加价率同时包含售价和需求导数，库存受限时销量等于可售量；商誉成本的导数还区分场景单位毛利是否为正。三档周级 SLSQP 均正常收敛，主方案使用两个可行初值复算，目标相对差为 `1.68e-8`，约束最大实质违规量低于 `2.31e-8`。因此本文将结果称为“数值优化方案”，不宣称严格全局最优。
