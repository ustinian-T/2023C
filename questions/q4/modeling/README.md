# 第四问建模说明

## 模型定位

第四问不重新构造补货定价优化器，而是审计前三问的不可观测变量和不稳定输入，回答“采什么、为什么、最少需要哪些、采后怎样证明有价值”。

## 核心结构

1. 从Q1-Q3正式JSON/CSV提取13项可追溯证据；
2. 定义库存缺货、批次损耗、供应履约、促销陈列客流、匿名购物篮、天气日历、竞争价格7个数据包；
3. 定义潜在需求、价格响应、动态损耗、供应成本、单品替代、外部需求、实际验证7项核心能力；
4. 在7个数据包的128个子集中枚举满足逻辑前置条件的最小组合；
5. 通过删一检验确认无冗余，通过7种结构情景统计稳健优先级；
6. 新数据产生后使用同窗口增量回测和Pareto支配评价，不预填假设提升率。

完整公式、字段、结果和模型边界见 `../report/第四问建模论文.md`。
