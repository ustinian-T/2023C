# 第四问输出

## tables

- `q4_gap_diagnostics.csv`：13项前三问诊断证据与来源；
- `q4_data_catalog.csv`：7类数据的字段、粒度、用途和隐私边界；
- `q4_coverage_matrix.csv`：数据包与8项直接能力的二元映射；
- `q4_minimum_portfolios.csv`：7种结构情景的全部最小组合；
- `q4_sensitivity_analysis.csv`：各数据包的情景包含率和三级优先级。

## results

- `q4_summary.json`：核心结果、证据、组合和后续回测协议；
- `q4_validation.json`、`validation_report.md`：27项独立检查。

## figures

三组正式图均提供300 dpi PNG和PDF：前三问证据、数据能力矩阵、优先级结构稳健性。
