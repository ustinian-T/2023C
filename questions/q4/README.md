# 问题 4：补充数据建议

## 任务

提出商超为改进蔬菜补货与定价决策还应采集的数据，并解释每类数据对前三问需求分析、预测、约束设定、收益优化和模型验证的帮助。

## 共享输入

- `problem/C题.pdf`：问题边界；
- `data/raw/`：当前已有的商品、销售、批发价和损耗率数据；
- `questions/q1` 至 `questions/q3`：已完成时可供识别数据缺口的模型与验证结果。

## 已完成方案

本问采用“前三问证据审计 + 逻辑能力覆盖 + 最小基数采集组合 + 结构情景灵敏度 + 增量回测-Pareto评价”。模型不为尚未采集的数据假定信息质量、误差缩减、先验分布、采集成本或EVSI，而是从前三问正式输出提取13项诊断证据，将7类候选数据映射到7项核心能力，并枚举全部128个子集。

完整核心链路得到唯一5包最小组合：库存与缺货、批次损耗与品质、供应商报价与履约、促销陈列与客流、匿名购物篮。删除其中任一数据包后均不再可行。7种结构情景中，库存缺货和促销陈列客流均为7/7必选；天气日历和竞争价格仅在扩展情景采用。
